# Arkdown 下载与组件

Arkdown 的公开下载仓库，由 ArkVibe，Inc. 维护。应用源码当前保持私有，之后再考虑开源。

## 可选文档转换组件

[下载 MarkItDown 组件 0.1.7 / Python 3.12.10](https://github.com/Lydiannnn/arkdown-releases/releases/tag/markitdown-0.1.7-py3.12.10)

适用于 Windows x64。请在配套版本的 Arkdown 中通过「偏好设置 → 文档转换」安装；应用会校验清单、文件大小和 SHA-256。第三方许可证随组件提供。

## Arkdown 应用

正式应用包将在准备就绪后发布到 [Releases](https://github.com/Lydiannnn/arkdown-releases/releases)。当前组件发布不包含 Arkdown 应用程序。
