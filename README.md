# Arkdown 下载与组件

Arkdown 的公开下载仓库，由 ArkVibe 维护。

## 可选文档转换组件

[下载 MarkItDown 组件 0.1.7 / Python 3.12.10](https://github.com/Lydiannnn/arkdown-releases/releases/tag/markitdown-0.1.7-py3.12.10)

适用于 Windows x64。请在配套版本的 Arkdown 中通过「偏好设置 → 文档转换」安装；应用会校验清单、文件大小和 SHA-256。第三方许可证随组件提供。

## 可选悬浮翻译组件

[下载悬浮翻译窗组件 1.0.0](https://github.com/Lydiannnn/arkdown-releases/releases/tag/screen-translation-engine-1.0.0)

适用于 Windows x64。新版 Arkdown 首次打开「工具 → 悬浮翻译窗」时可按需安装，下载约 103 MB，支持取消和重试；安装后再次打开无需重新下载。应用会校验下载包与解压文件。支持现有大模型与百度快译配置。

OCR 在本机完成；翻译内容按用户选择发送至相应服务。许可证与必要的第三方源码材料随发布提供，不包含私有应用源码。
